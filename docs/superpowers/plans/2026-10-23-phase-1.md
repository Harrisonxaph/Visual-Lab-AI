# Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a responsive private live detection lab and Phase 1 PR.
**Architecture:** Independent camera, detector worker, request scheduler, visualization and UI modules. One frame in flight, CPU/WASM, local frames only.
**Tech Stack:** TypeScript, Vite, MediaPipe Tasks Vision, Vitest, Playwright.
**Spec:** ARCHITECTURE.md (approved 2026-10-23).

## Global Constraints

Phase 1 only; no paid API, raw-frame upload, merge or deployment. Preserve roadmap and assistant docs.
Codex implements; Claude reviews. No fabricated reviewer or real-device evidence.
Threshold 0.05–1 inclusive; model output floor 0.05 and result cap 50. CPU worker required.

## Review Focus

- Stop during pending camera permission must release late streams.
- Pause/stop/restart must discard stale frame results and release bitmaps.
- Worker crash/timeouts and externally ended tracks must be recoverable.
- Orientation/aspect changes must align overlay and video on mobile.
- Hidden page and unavailable storage must not break the lab.
